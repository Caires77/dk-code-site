# DK CODE — Desenvolvimento Web Premium

Site institucional da DK CODE para apresentar serviços de desenvolvimento web, portfólio, processo, parceiros e atendimento direto via WhatsApp.

## Desenvolvimento local

```bash
pnpm install
pnpm --filter @workspace/dk-code-site run dev
```

## Publicação no Vercel

O projeto já inclui `vercel.json` com o comando de build e a pasta de saída configurados. Ao importar este repositório no Vercel, mantenha a raiz do projeto e use o gerenciador `pnpm`.

## Contato

Os CTAs de contato abrem o WhatsApp da DK CODE com mensagens pré-preenchidas. O site não usa formulário.
